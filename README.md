# Ice Snow City — 冰雪城市轻量策略游戏

Ice Snow City 目前是**可玩的移动横屏网页开发预览**，不是已经正式发布的 iOS/Android 应用。玩家经营一座现实风格的冰雪城市；所有地块、建筑和物资都是游戏内容。**NFT 已彻底移除；ISC 保留为游戏内余额，可在游戏中领取、保存和消耗。钱包签名保留为可选的地址控制权验证，不用于 NFT 资产操作。**

## 现在可以玩什么

- **城市街区：**六个现实风格街区，各一张移动端 WebP 底图；统一时钟实现连续昼夜过渡。单指轻点路面定位、拖拽路面跟随移动；长按方向键连续行走；可触碰地点标记并走访。
- **城市运营：**住宅、生产、商业和公共服务共同构成资源循环。运行一轮消耗水电并产生物资/ISC；领取 ISC 后可消耗 1 ISC 补给水电。建筑升级、停机、资源趋势和危机提醒都在此页及可展开的资源侧栏。
- **城市供应目标：**走访生产园食品加工坊和商业街鸿运商都、运营一轮、完成一次水电补给，宜居度 +5，奖励只发一次。
- **浏览器本机存档：**保存区域、游戏时钟、资源和任务进度；仅限当前浏览器/设备，清理网站数据可能丢失进度，**尚非跨设备账号存档**。

游戏主导航仅有**城市街区**和**城市运营**。此前的 NPC、社交、农场、资产商城、Babylon 3D 总览等旧模块不作为当前可玩主界面的入口，历史源码并非已完成的玩法。

## 运行与验证

```bash
pnpm install
pnpm dev                    # 本地浏览器打开 http://localhost:3000/game
pnpm exec vitest run --maxWorkers=2
pnpm check
pnpm build
python3 scripts/smokeMobileTouch.py  # Chromium 844×390 与 667×375 横屏触控模拟
```

触控烟测需本地 Chromium（`/usr/bin/chromium`）和 Python Playwright；也可以给脚本传入游戏预览 URL。**模拟器通过不代表真机通过。**非游戏端点与尚存的历史文档不可作为本游戏的最终产品承诺。

技术栈：React 19、Tailwind CSS 4、tRPC、Express、Drizzle；当前六区场景主流程以 2.5D 图片+DOM 热点呈现，不依赖加载高保真 GLB 才能开始玩。

## 发布状态

目前仅有开发预览和可生成的生产构建，**没有已验证的正式发布域名**。上线之前仍需 iPhone Safari 和 Android Chrome 的横屏触控、可读性与稳定性验收，扩充可重复策略决策，以及生产部署后从开场至恢复存档的完整烟测。见 [实际可玩版本与上线收口](./docs/ICE_SNOW_CITY_LAUNCH_CUT_2026-10-02.md)。
