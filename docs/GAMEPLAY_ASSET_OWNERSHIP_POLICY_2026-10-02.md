# Ice Snow City 游戏内资产所有权策略

**生效日期：** 2026-10-02  
**适用范围：** 地块、住宅、商业建筑、生产建筑、公共设施、农业设施、城市地标及其升级状态

## 结论

Ice Snow City 的地块与建筑**不再作为 NFT 核心资产**。它们只属于游戏内资产，用于场景交互、建造、升级、生产、维护、收益领取和游戏存档。

## 游戏内资产允许的操作

- 放置、移动和拆除（按游戏规则）；
- 建造、升级、启用、停机和维护；
- 生产资源、消耗资源和领取游戏内收益；
- 在游戏存档中记录位置、等级、状态、产出和外观；
- 通过游戏内市场或模拟经济进行展示和交互。

## 明确禁止的误用

- 不为地块或建筑执行 NFT 铸造；
- 不把地块或建筑作为 ERC-721/ERC-1155 核心资产转移；
- 不在钱包、区块浏览器或 NFT 市场中宣称拥有其链上所有权；
- 不将游戏内估值解释为可兑现的链上资产价值；
- 不在分享海报、个人中心和公共资产列表中使用“土地 NFT”“建筑 NFT”“Token ID”等误导性表述。

## 链上模块边界

现有 NFT/Seaport/铸造代码属于历史实验或未来扩展模块，不得被游戏内地块与建筑调用。任何新的链上资产类别必须先获得单独的产品定义、合约审计、经济模型和发布门禁批准，并使用与地块/建筑不同的类型和命名空间。

## 验收要求

1. 前端地块和建筑操作不发起钱包签名、approve、mint 或 transfer；
2. UI 使用“游戏内资产编号”或“建筑等级”，不使用 Token ID；
3. 资产数据以游戏状态为准，链上余额仅用于 ISC 钱包/代币相关功能；
4. 真实高保真 GLB/PBR/LOD 资产仍是美术交付证据，不等于 NFT 资产证据。
