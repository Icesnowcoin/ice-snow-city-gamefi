# GitHub 历史令牌安全处置记录

**记录原则：本文件不包含任何令牌、私钥、会话值或可恢复凭据。**

## 当前检测结果

仓库级 `scripts/scan-secrets.sh` 已用于检查当前工作树中的高置信度 GitHub Token、私钥和常见 API Token 模式。当前代码与文档清洁快照未新增凭据内容；此前历史会话文档曾被标记为存在需要处置的 GitHub Token 风险，因此不能把当前扫描通过解释为历史凭据已经失效。

## 必须执行的处置顺序

历史 GitHub Token 必须在 GitHub 账户的 Developer settings 中立即撤销，然后创建具有最小权限、最短有效期的新凭据，并通过平台安全密钥管理录入，不得写入仓库、`.env`、Markdown、测试夹具或日志。撤销后应再次运行仓库扫描，并在 GitHub Actions 与本地凭据存储中检查旧凭据是否仍被引用。
