# Ice Snow City Draft 合约审计与部署前门禁

**状态：仅审计准备，不代表审计通过、部署完成或可安全用于主网。**

## 当前范围

本门禁覆盖 `TaxSystem.sol` 与 `ISCSeaportStyleMarketplaceOffersDraft.sol`。两者均属于不可升级 Draft 合约，当前工作只做源码级静态核对、集成边界记录和部署前清单，不执行部署、代币转账、NFT 转移或任何链上写入。

| 合约 | 当前用途 | 已观察到的权限面 | 当前结论 |
|---|---|---|---|
| `TaxSystem` | 玩家主动授权后结算场景税费 | 构造函数写入不可变 ISC、国库、营销钱包和费率；无 owner、proxy、mint 或 pause | 可进入第三方审计准备，不能视为已审计 |
| `ISCSeaportStyleMarketplaceOffersDraft` | EIP-712 SELL 与 BUY_OFFER 订单结算 | 构造函数写入不可变 ISC 与国库；无 owner、proxy、mint 或 pause；用户自行 approve NFT/ISC | 可进入第三方审计准备，不能视为已审计 |

## 必须保留的经济参数

`TaxSystem` 将场景消费总额按 **60% 国库 / 40% 营销钱包** 分配。NFT 市场 Draft 使用 **10% commission**，即 `COMMISSION_BPS = 1_000`；当前实现把这笔市场手续费全部发送到 `treasury`，没有自动执行 NFT 铸造使用的 **1% 销毁 / 69% 国库 / 30% 营销** 规则。三类经济规则不能混用，前端和后端必须按业务场景分别展示并在交易确认前提示用户。

## 源码级风险与必须验证事项

| 优先级 | 项目 | 发现或风险 | 发布前要求 |
|---|---|---|---|
| P0 | 外部审计 | 当前没有第三方审计报告、部署字节码或验证地址 | 由独立 Solidity 安全团队完成源码、字节码、模糊测试和不变量审计，并公开报告 |
| P0 | 真实地址 | 国库、营销钱包、ISC、NFT 合约地址必须与目标网络一致 | 使用多方复核的网络配置；部署前禁止使用占位地址 |
| P0 | 代币行为 | `transferFrom` 返回值、非标准 ERC-20 行为、扣税/转账失败回滚需要验证 | 使用经过验证的 ISC ERC-20；增加 fork/testnet 测试和余额不变量 |
| P0 | NFT 转移 | ERC-721/1155 `safeTransferFrom`、授权撤销、接收方合约兼容性需要验证 | 增加恶意接收合约、重入、失效授权和转移失败测试 |
| P1 | 签名域 | EIP-712 domain name/version、chainId、verifyingContract 和前端编码必须完全一致 | 用 ethers/viem 双实现交叉生成 hash，并在目标网络回归验证 |
| P1 | 订单状态 | `settled` 和 `cancelledNonces` 防止重复成交，但取消、过期、签名重放和跨市场重放仍需审计 | 覆盖 nonce 取消、订单取消、过期、重复成交、错误签名和链切换测试 |
| P1 | 价格与金额 | `price`、`amount`、费率乘法、整数除法和极端数值需要做边界分析 | 增加 fuzz/property tests，验证 seller + commission == price |
| P1 | 资产归属 | SELL 订单的卖方资产归属最终由 NFT 转移调用验证；BUY_OFFER 先检查当前持有人 | 覆盖转移前转卖、ERC-1155 数量不足和授权变化测试 |
| P2 | 税费展示 | `expectedTotal` 用于防止界面与参数不一致，但前端仍需固定输入快照 | 确认预览值、交易参数和用户签名确认值完全一致 |
| P2 | 可运维性 | Draft 没有 pause 或管理员恢复入口；错误部署无法升级修复 | 部署前确认不可升级是产品决策；准备停用/迁移方案而非添加隐式管理员 |

## 部署前硬门禁

只有在以下条件全部满足后，才允许从 testnet 进入 mainnet 评估：源码已锁定并生成审计提交；第三方审计报告已归档；目标网络编译器版本、优化器配置和构造参数已复核；ISC、国库、营销钱包和 NFT 合约地址已通过独立渠道确认；EIP-712 domain 和链 ID 已在前后端双向回归；测试覆盖失败转账、重入、重放、过期订单、取消订单、授权变化和极端金额；部署字节码已在浏览器完成源码验证；事件索引器能够正确处理 `TaxesCollected`、`OrderSettled`、`OrderCancelled` 和 `OrderNonceCancelled`；最后才可进行小额 testnet 交易演练。

> **禁止项：** 在缺少第三方审计、未完成地址复核、未验证字节码或未完成 testnet 演练前，不得执行主网部署、真实 ISC 结算或 NFT 资产转移。

## 当前可自动完成与不可伪造部分

当前可以自动完成的是源码静态核对、前端签名参数检查、测试用例、配置一致性检查、部署清单和审计证据归档。无法凭空生成的是第三方审计结论、真实部署交易哈希、浏览器源码验证状态、外部钱包多方签署和历史 GitHub Token 的撤销结果；这些状态必须继续保持为未完成门禁。

## UI 网络模式切换安全边界（2026-08-29）

界面新增测试网/主网模式入口。默认模式为受控测试网演示，显示 local-hardhat/测试网语义和 chain ID `31337 / 97`；该模式不使用真实资金，Draft 合约保持只读边界。

主网选项目前仅是只读预览。用户必须完成显式确认后才能切换界面模式，页面会显示 chain ID `56`、第三方审计尚未完成以及真实写入关闭等提示。该开关不调用钱包切链、不签名、不支付 Gas，也不提交真实交易；它不能被解释为主网已经获得部署批准。

模式选择使用浏览器 localStorage 持久化，但在存储不可用时安全回落到测试网。生产开放真实主网写入仍需完成合约审计、源代码/字节码验证、权限审查、生产 RPC、索引器和多方批准。

## 主网只读交易按钮提示（2026-08-29）

主网只读预览下，出价提交和接受报价等真实交易按钮保持禁用，并由统一 Tooltip 提供桌面悬停、键盘聚焦及移动端可触达说明。提示明确当前仅为预览，不会签名、支付 Gas 或提交链上交易；预计开放时间不承诺具体日期，仅在第三方审计、测试网演练、真实资产和生产基础设施门禁完成后评估。

## 主网上线通知订阅（2026-08-29）

主网只读预览中提供邮箱订阅入口。用户必须明确勾选“仅接收主网上线通知”，服务端仅保存规范化邮箱、active 状态、来源和时间戳；唯一邮箱约束保证重复提交幂等恢复，不建立营销画像。

当前实现只记录订阅意向，不代表邮件已经发送，也不承诺主网开放日期。正式通知发送仍需单独接入经过授权的邮件服务、退订机制、隐私政策和运营审批；在这些条件具备前，界面不会宣称已发送邮件或已确定上线时间。

### 订阅成功反馈动效

首次新增订阅成功后，界面在订阅表单范围内显示一次约 1.8 秒的轻量冰雪主题 Confetti。重复订阅不会触发庆祝效果，避免把幂等恢复误报为新事件。启用 `prefers-reduced-motion: reduce` 时，粒子保持静态低强调显示，仅保留成功状态文字和图标；该反馈不代表邮件已发送或主网已上线。

### 界面隐私声明

邮箱输入框下方明确显示：邮箱仅用于主网上线通知，不用于其他用途。该界面声明与服务端的最小化订阅字段、明确同意和当前不发送邮件边界保持一致；任何后续邮件服务接入仍需补充退订、隐私政策和运营审批。

### 订阅提交中的交互保护

点击“订阅更新”后，按钮显示 Loading Spinner 并设置 `aria-busy`，邮箱输入、用途确认和提交按钮在请求完成前暂时禁用，以避免网络延迟导致重复提交。成功、重复订阅或失败回调后恢复交互；该状态只表示请求处理中，不代表邮件已发送或主网已上线。

### 订阅成功后的 Twitter/X 分享

仅当新订阅成功时显示“分享到 Twitter”按钮。按钮通过公开 `intent/tweet` URL 打开预填文案，不自动发布、不读取用户社交账号信息、不携带邮箱或其他敏感数据；文案仅表达已订阅主网上线通知，不虚构具体上线日期或主网已上线状态。

### Twitter/X 分享直达游戏入口

订阅成功后的 Twitter/X 公开分享链接现在指向实际存在的 `/game` GameHub 路由，而不是站点根路径。中英文文案突出 Ice Snow City 的冰雪都市建设体验，但不宣称主网已经开放、不承诺具体上线日期；分享仍由用户在 Twitter/X 页面自行确认发布。
