# Ice Snow City 前端画面与地图显示核验

## 核验结论

当前 `/` 与 `/game` 均能进入同一个 `GameHub`，开场层点击“进入游戏”后可看到城市主画面、地图画布、建筑、NPC、玩家标记、收益卡片、城市行动指南和底部功能导航。浏览器控制台在本次核验中未发现客户端错误，开发服务保持运行。

地图“显示正常”的范围是：GameHub 内的 **Canvas 2D 城市场景**可见且内容可辨识，画布中显示 5 个基础建筑、4 个 NPC、玩家位置和已布置资产；默认 3 栋收益建筑的收益进度卡片也能显示。当前实际绘制代码位于 `client/src/components/game/PlayableGameScene.tsx`，使用 Canvas 2D API，而不是 Babylon.js 3D 场景。

## 关键差异与风险

| 项目 | 核验结果 | 影响 |
|---|---|---|
| `/` 默认路由 | 正常落到 `GameHub` | 可进入主场景 |
| `/game` 路由 | 正常落到同一 `GameHub` | 分享入口与首页一致 |
| 主场景地图 | 可见的 Canvas 2D 网格地图 | 可玩原型正常，但不是最终 3D 城市 |
| Babylon 农业地图查看器 | 存在于 `AgriculturalMapViewer.tsx`，但未被 GameHub 主入口挂载 | 不能据此认为主入口已接入 Babylon 3D |
| 建筑/NPC/玩家 | Canvas 中可见 | 基础视觉交互路径存在 |
| 桌面布局 | 地图可见，但左侧导航、右侧资产/行动面板会遮挡画布部分区域 | 画面适合功能演示，不适合作为最终全屏游戏 HUD |
| 竖屏移动端 | 显示“请将设备旋转至横屏”提示 | 符合横屏产品约束 |
| 横屏移动端 | 以横屏为目标，但应继续在真实设备上验证安全区、触控和画布缩放 | 当前截图工具横屏冷启动可能停留在开场/视口状态 |
| 控制说明 | 主场景仍展示方向键/WASD 文案 | 不符合纯手游触控交互定位，需要后续替换为虚拟摇杆/触控提示 |

## 本次结论

本次未发现导致地图完全空白、路由错误或浏览器客户端异常的运行时故障，因此没有进行代码修复。需要明确的是，**当前游戏前端画面可以运行并显示地图原型，但不能宣称主入口已经显示最终 Babylon.js 3D 城市地图**。若上线目标是 3D GameFi 城市，应把真实 Babylon Engine/Scene、四大功能区块、GLB/PBR 资产和触控相机控制接入 `GameHub` 主路径，并在真实 iOS/Android 横屏设备上复核。
