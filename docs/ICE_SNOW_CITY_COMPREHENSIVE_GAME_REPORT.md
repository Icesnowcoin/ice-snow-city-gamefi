## 一、 项目概述与世界观架构

《Ice Snow City》是一款基于现代冰雪都市模拟经营与 GameFi 经济体系构建的高沉浸感 2.5D/3D 复合网页游戏。项目立足于“无冷 weapons（冷兵器）、纯现代化高科技与极地冰雪交织”的核心美学，融合了城市基建规划、农作物供应链、房地产收购、银行理财及 Web3 经济循环。

项目整体采用现代 Web 全栈架构：
* **前端**：React 19、Tailwind CSS 4、Babylon.js（3D 场景与地图）、Three.js（3D 角色与资产预览）、HTML5 Canvas（2D 模拟经营引擎）、Vaul（移动端抽屉组件）。
* **后端**：Node.js、Express、tRPC 11、Drizzle ORM（MySQL/TiDB 兼容）、Manus OAuth 安全认证、S3 对象存储与自动 WebGL 兼容性守护。

## 二、 核心参数指标与经济模型

游戏内经济与治理体系完全围绕 **ISC (Ice Snow Coin)** 展开，确立了透明且可持续的经济循环：

### 1. 代币与经济属性
* **治理代币**：ISC 为 ERC-20 标准代币，已完成合约所有权放弃、代理放弃及控制权剥离，作为全游戏唯一的交易媒介。
* **交易中心与国库税收**：玩家可在游戏内的 TradingCenter 中自由交易土地、建筑与道具。所有市场交易均自动抽取 **10% 的佣金**，其中大部存入国库地址（`0x3B79D4A0bd73FCaB12DFEd34dA830b376A50e019`），用于持续反哺游戏内需。
* **NFT 铸造与销毁机制**：
  * **1%** 永久发送至合约地址销毁（通缩机制）。
  * **69%** 归属国库地址，用于支持游戏长线生态建设。
  * **30%** 归属营销钱包地址（`0xF8A408495941ea30451Da613dC846Dcae47890f0`）。
  * 所有铸造产生的 Gas 费及 ISC 消耗均由玩家承担。

### 2. 工程与代码量指标
* **生产源代码规模**：约 **135,320 行**（含前端 UI、游戏引擎、后端 tRPC 路由与业务工具）。
* **测试代码规模**：约 **27,421 行**（覆盖手势交互、商城加购、资产验证、错误报告与 WebGL 降级）。
* **核心模块分布**：前端 UI 与渲染占 70.36%，后端业务逻辑占 27.01%，数据库与 Schema 占 1.55%。

## 三、 核心玩法与系统模块

项目在过去数个阶段中迭代并交付了以下核心玩法与系统：

1. **2.5D 伪 3D 模拟经营与开放世界**：
   - 包含 `RTSGameEngine` 等轴测经营网格与 `PlayableGameScene` 开放世界场景，支持房屋、农场、商城、工厂、银行等现代建筑建造与 NPC 互动。
2. **农业区 3D 场景与自然生态系统**：
   - 基于 Babylon.js 构建的 500×500 农业都市地图。
   - 动态集成**昼夜交替**、**暴风雪/雨/晴天天气系统**、**四季植被更替**与**季节环境音效**。
   - 搭载 **2D 小地图实时坐标追踪** 与 **相机自动导览巡游模式**。
3. **移动端手势优先的商城与抽屉架构**：
   - 采用触控友好的 `MobileBottomSheet` 抽屉组件替代传统悬停菜单。
   - 支持向下滑动关闭、左右滑动分类切换、加购成功动画、触觉反馈、NPC 专属资产互动入口及**心愿单快速加购**。
4. **3D 角色与资产触控预览系统**：
   - 完美支持单指旋转、**双指捏合缩放 (Pinch-to-zoom，78%–135% 边界限制)**、**双击重置 (100%)** 及画布右下角轻量级**一键重置视角按钮**（带多语言悬停 Tooltip）。
   - 支持 `stand`（站立）、`walk`（行走）、`interact`（互动挥手）动作切换，`0.5x/1x/2x` 播放速度调节与播放/暂停控制。
   - 搭载高保真 `.glb` 角色资产的运行时加载验证与**实时加载进度条**。
5. **开场动画与音效沉浸体验**：
   - 首屏集成用户定稿的冰雪都市夜景海报（`IMG_8014.WEBP`），配以沉浸式冰雪都市交响背景音乐与右下角毛玻璃静音/取消静音悬浮控制按钮。
6. **WebGL 兼容性守护与一键诊断报告**：
   - 自动检测客户端 3D 渲染上下文，在硬件加速受限或无头环境中平滑降级至 2D 简化模式。
   - 内置一键发送错误报告（同步后端并通知管理员）与常见问题解答 (FAQ) 可折叠答疑面板。
