## 一、 概述

在《冰雪城市》(Ice Snow City) 的现代冬季城市模拟建设中，高精度的角色动画与流畅的状态机切换是提升游戏真实感与玩家沉浸感的核心。本说明书确立了 Phase 69 中 10 套核心动作资产（待机、行走、奔跑、工作、睡眠、庆祝、悲伤、对话、挥手、跳跃）的动画混合、状态转换与运行时调度规范。

## 三、 动画状态机 (Animation State Machine) 逻辑

1. **过渡混合 (Cross-fade Blend)**：
   - 任何两个动作状态之间切换时，采用 0.15s - 0.25s 的线性插值混合，避免姿态突变。
2. **优先级调度**：
   - 快捷动作（如挥手、跳跃、庆祝、悲伤）拥有高层级中断权重，播放完毕后自动平滑回归当前的基础移动或待机状态（Idle/Walk/Run）。
