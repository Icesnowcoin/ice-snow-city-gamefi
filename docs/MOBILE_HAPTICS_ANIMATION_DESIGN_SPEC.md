# Ice Snow City 移动端触觉反馈与动画设计方案

## 1. 概述与设计哲学

作为一款以现代化都市模拟经营、区块链经济（ISC）与多人社交为核心的沉浸式手游 [1]，**Ice Snow City（冰雪城市）** 必须彻底摒弃传统的桌面端鼠标悬停（Hover）与复杂指针交互模式。移动端的核心交互基石在于**“触觉驱动（Touch-Driven）”、“物理直觉（Physics-Intuitive）”与“即时反馈（Immediate Feedback）”**。

本方案旨在为 Ice Snow City 建立一套完整的移动端触觉反馈、交互动效、状态切换及无障碍适配标准。通过将 Web 端原有的悬停逻辑全面转化为基于点击（Tap）、长按（Long Press）、拖拽（Pan）与捏合（Pinch）的手势矩阵，并结合浏览器的 Vibration API 与硬件加速动画，确保玩家在手机端获得媲美原生顶级手游的丝滑质感。

---

## 2. 移动端触觉反馈系统（Haptic Feedback Matrix）

在移动端游戏中，触觉反馈是连接虚拟经济与现实物理感官的桥梁。为了避免过度震动导致的疲劳，同时强化关键经济行为（如 ISC 结算、NFT 铸造、地产买卖）的仪式感，项目组将触觉反馈划分为四级强度模型。

| 触觉反馈级别 | 触发场景示例 | 震动模式（Web Vibration API / 手机端） | 心理暗示与设计目标 |
| :--- | :--- | :--- | :--- |
| **轻量级 (Light)** | 切换标签页、点击普通按钮、切换商城分类 | `10ms` 极短脉冲 | 模拟真实机械按键的清脆感，提供基础确认。 |
| **中量级 (Medium)** | 成功将商品加入购物车、选中地图区块热点、点赞好友 | `30ms` 稳定震动 | 确认操作已生效，建立多级菜单的物理边界。 |
| **重量级 (Heavy)** | 核心建筑放置成功、主线剧情任务完成、达成繁荣度里程碑 | `50ms - 20ms - 50ms` 复合波形 | 创造高价值成就感，突出重大游戏节点。 |
| **警示级 (Error/Alert)** | 余额不足（ISC 不够）、建筑碰撞越界、交易失败 | `80ms` 连续双振 | 提供即时纠错反馈，防止错误操作继续扩大。 |

## 3. 核心交互动效与手势规范

针对移动端触摸屏的物理特性，所有 UI 组件与 3D 渲染场景必须遵守以下动效与手势转换准则：

### 3.1 消除 Hover 依赖，转向 Active 与 Touch 态
- **点击响应 (Active Scale)**：所有按钮与卡片在手指按下（`touchstart`）时，必须在 `100ms` 内缩小至 `scale(0.97)`，松开时以弹簧曲线回弹至原大，提供即时视觉确认。
- **长按触发 (Long Press)**：替代桌面端的悬停预览。长按道具卡片、NPC 头像或建筑 0.5 秒，即可呼出详细属性面板或快捷操作菜单。
- **面板切换与滑动**：底部抽屉（BottomSheet）与全屏模态框统一采用从底部或侧边滑入的动画，过渡时长控制在 `250ms - 350ms` 之间，配合贝塞尔曲线 `--ease-out: cubic-bezier(0.23, 1, 0.32, 1)`。

### 3.2 2.5D/3D 城市地图与建筑放置动效
- **区块热点点击**：在全局地图概览中，点击任意功能区块（如商业街、滑雪场、大学城、医院）后，镜头以平滑补间动画切入该区块，同时在底部弹出速览卡片。
- **建筑放置反馈**：当玩家在地图上放置房地产 NFT 或商业建筑时，合法放置区呈现**呼吸感翡翠绿高亮边框**，冲突区呈现**警示红脉冲边框**，并伴随轻量级震动。

## 4. 关键系统在移动端的具体落地

### 4.1 道具商城与心愿单系统
- **商品卡片**：取消悬停发光与悬停加购按钮。改为点击卡片弹出精美详情模态框，模态框内部集成沉浸式大图、背景故事、价格与一键购买/加购按钮。
- **迷你购物车与心愿单**：通过顶部固定的悬浮胶囊按钮，点击后展开全屏或半屏抽屉式面板，支持单项移除、数量调整与快速结算。

### 4.2 城市主线剧情与繁荣度里程碑面板
- **繁荣度进度条**：点击进度条或“里程碑说明”区域，即可展开详细的阶段目标提示（如“进入繁荣扩张期：解锁区域自动化供应链与客流量 +50%”），再次点击折叠。
- **任务领取**：点击“领取奖励”按钮时，触发中量级触觉反馈，并伴随金币与 ISC 代币数字跳动动画。

---

## 5. 无障碍与性能优化规范

- **触控热区（Touch Target Size）**：所有可点击元素的最小尺寸不得小于 `48px × 48px`，确保不同尺寸的移动设备均能精准点击。
- **动画硬件加速**：所有动效严格限制在 `transform` 与 `opacity` 属性上，避免触发浏览器的重排（Reflow）与重绘（Repaint），保证移动端稳定维持 `60 FPS`。
- **减少运动模式 (Prefers Reduced Motion)**：自动检测系统的无障碍设置，对关闭动效的用户提供直接切换的静态视图。
