# GameHub Babylon.js 测试地块与建筑

## 交互样板

AgriculturalMapManager 现在会在地图初始化阶段创建三个程序化测试对象：瑞景华府、鸿运商都和丰盈智造园。名称采用更吉祥的城市命名，同时保留原有内部 ID，以避免影响点击映射和后续数据兼容。每个对象包含浅色地块底座与独立建筑网格，使用现有 `MeshObjectMapper` 注册到地图选择链路，因此点击地块或建筑都能得到同一个 Building 对象。

| 对象 | 类型 | 场景位置 | 主要用途 |
|---|---|---:|---|
| 瑞景华府 | farmhouse | (-72, -34) | 住宅样板；寓意祥瑞景致、安居兴旺 |
| 鸿运商都 | storage | (8, -28) | 商业样板；寓意鸿运汇聚、商贸繁荣 |
| 丰盈智造园 | greenhouse | (74, -12) | 生产样板；寓意丰收充盈、现代智造 |

## 提示框

当测试对象被选中时，地图画布右下角显示简要信息提示卡，包含对象名称、类型、繁荣度/生产效率、健康度和维护成本。提示卡使用 `role="status"` 与 `aria-live="polite"`，并提供触控尺寸合适的关闭按钮；点击空白地图或关闭按钮会清除选中状态。

Babylon 的现有点击、鼠标移动和滚轮逻辑仍由 AgriculturalMapManager 负责；画布使用 `touch-none`，因此移动端点击对象与桌面点击复用同一选择回调。当前测试模型是程序化几何，不代表最终 GLB/PBR 美术资产，后续可按同一对象映射契约替换网格。显示名称与内部 ID 分离：`test-aurora-residence`、`test-crystal-market`、`test-frost-factory` 保持不变，后续可安全调整本地化名称。

## 验证边界

本次验证重点是对象创建、对象映射、提示卡渲染和生命周期清理。真实设备上的单指点按、不同相机缩放下的可点击面积以及最终美术资产的碰撞/层级仍需在 iOS/Android 横屏设备上复核。
