# Ice Snow City 资产验收清单

## 资产身份与授权

- [ ] Asset ID、文件名、目录和版本一致。
- [ ] 作者、来源、许可证和商业使用范围已登记。
- [ ] 资产已写入 manifest，状态与真实文件一致。

## 视觉质量

- [ ] 符合现代冰雪商业都市和 2.5D 伪3D视觉 DNA。
- [ ] 使用官方 ISC Logo 资源，不自行重绘、变形或扩展品牌文字。
- [ ] 色彩符合冰蓝主色、暖色强调和功能色层级。
- [ ] 角色是完整全身形象，并附职业/背景描述。
- [ ] 建筑升级前后有可识别的视觉变化。

## 技术质量

- [ ] GLB 可被 Babylon.js 真实加载，且无关键资源丢失。
- [ ] 面数、骨骼、纹理分辨率和文件大小符合资产类别预算。
- [ ] PBR 通道完整，运行时纹理为 KTX2/WebP 或有明确例外说明。
- [ ] LOD0/LOD1/LOD2 切换稳定，远景没有明显跳变。
- [ ] 碰撞体是简化体，且与可走/不可走区域一致。
- [ ] 动画命名、帧率、时长、循环标记和 0.3 秒过渡通过校验。
- [ ] 烟雾、冰蓝光效和天气粒子没有超出移动端粒子预算。

## 游戏集成

- [ ] 16:9 横屏下可读、可触控，关键控件触控目标不小于 44px。
- [ ] 资产加载失败时显示诚实的待导入或程序化回退状态。
- [ ] 交互点、生产点、收获点、导航和区块边界均已验证。
- [ ] 未引入武器、战斗化或中世纪幻想元素。
- [ ] 真实设备或目标性能档位的运行时回归结果已附上。
