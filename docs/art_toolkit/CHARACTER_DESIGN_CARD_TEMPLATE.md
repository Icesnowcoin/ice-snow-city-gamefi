## 视觉设计

| 项目 | 规格/描述 |
|---|---|
| 身高与比例 | 改良 Q 版，头部约占身高 1/3 |
| 脸型 | 从项目允许的脸型集合选择，并附正面/三分之四视图 |
| 肤色 | 使用 8 色基础范围之一，避免角色之间同质化 |
| 发型/发色 | 记录发型 ID 与颜色值 |
| 服装 | 现代都市商务、街头或职业制服；禁止武器化设计 |
| 配饰 | 说明材质、挂点和是否可拆换 |
| 主色 | 冰蓝/深蓝/雪白为基础，暖色仅作职业或稀有强调 |
| 背景描述 | 用 80–150 字说明人物经历、职业目标和社交关系 |

## 技术交付

| 检查项 | 目标 |
|---|---|
| GLB 文件 | `<asset-id>.glb`，真实文件交付后登记 URL |
| 面数 | 玩家 15k–25k tris；NPC 10k–20k tris |
| 骨骼 | 玩家 60–80；NPC 50–70 |
| 纹理 | 玩家身体 2K、服装 1K；NPC 1K–2K，优先 KTX2/WebP |
| 动画 | idle、walk、run、work、sleep、celebrate、sad、talk；30 FPS |
| 表情 | neutral、smile、sad、angry、surprised、tired、thinking、happy |
| LOD/碰撞 | 近中远景 LOD，胶囊或简化身体碰撞体 |
| 授权记录 | 记录作者、来源、许可证和允许的商业用途 |
