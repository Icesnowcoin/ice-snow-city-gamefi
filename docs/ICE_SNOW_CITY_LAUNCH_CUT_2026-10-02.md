# Ice Snow City｜实际可玩版本与上线收口（2026-10-02）

**状态：可玩的浏览器开发预览，不是已发布的正式游戏。**当前主产品选择手机横屏、现实生活冰雪城市、2.5D 单底图；NFT 已删除，ISC 保留为游戏内余额，支持领取、保存与消耗；钱包签名保留为可选的地址控制权验证，不用于 NFT 资产操作。此文件仅记录能在现有版本中验证的行为和未完成项。

## 已在游戏中实现

- `/game` 的开场使用与实际可玩商街相同的冬季街景；点“进入游戏”直接进入，不要求登录或钱包签名；钱包签名可从钱包授权页按需使用。旧的科幻都市/冰晶计分开场已从现行入口移除。
- 可在同一个地图界面切换**现代冰雪商业街、城市核心广场、瑞景住宅区、丰盈生产园、金融服务区、冬季农业基地**六区。每区只有一张 16:9 压缩 WebP 底图；昼夜由统一游戏时钟、全局暗色层和局部暖灯产生，不再制作日夜两套大图。六张图片由游戏存储返回 HTTP 200，单张约 0.27–0.35 MB。
- 可点路面移动纸片人、用方向键/WASD/触屏方向键移动、点标记打开地点信息卡并“走访”；**食品加工坊和鸿运商都**的走访计入下述目标，其他地点暂为生活街景展示。
- 场景内直接点击“运营一轮”：住宅提供劳动力、生产消耗水电产生物资、商业处理物资产生待领取 ISC、公共服务维护宜居度；在运营页领取 ISC 后，点击“补给水电”会消耗 1 ISC，再继续经营。建筑停机和升级仍在下方原有资源面板中。
- 首条轻量策略目标“城市供应”要求：走访食品加工坊→走访鸿运商都→运营一轮→用 ISC 补给水电；四步可任意顺序完成，达成后宜居度 +5，奖励仅发一次。默认收起的目标提示不遮挡街景热点。
- 本机游戏时钟、上次所处区域、资源、升级级别、运行状态、资金、走访和目标进度采用版本化浏览器本地存档；刷新后保留。**仅限当前浏览器和设备**，清理站点数据会丢失，不能称作账号存档。
- 游戏服务器启动不自动建立旧 NFT 客户端或轮询 NFT 事件；ISC 项目 token 信息与钱包签名模块保留在仓库中，但当前游戏内余额、领取与消耗使用可恢复的游戏存档状态，不把 NFT 流程带回主界面。

## 实测范围与限制

- 浏览器里实际验证过：商业街与广场图片切换、冬季温室底图、运营一轮使水由 60→56、物资 0→2、补给水电恢复到 60/80；刷新后仍保留冬季温室和第 1 轮状态；普通 `/game` 开场按钮可进入游戏。
- 定向 Vitest 覆盖了六区单图、昼夜插值、走访、移动、经济循环、补给、目标、存档、通知和开场；目标接入后的**全量回归 223 文件/2248 测试通过**，TypeScript 与生产构建通过。浏览器内实际完成了“生产区走访→商业区走访→运营→领取收入→补给水电”，城市宜居度奖励只发放一次；已修正地点卡遮挡补给按钮的问题。**这些不等于 iOS/Android 真机合格证据。**
- 当前页面是 WebDev **开发预览**，此前自动发布通知为失败且无正式域名；不能将该临时预览网址宣传为公开上线。本会话未提供单独的 WebDev 正式发布工具。

### 真机验收预检

在连接 Android 手机或设备云后，先运行：

```bash
python3 scripts/check_real_device_prerequisites.py --json
```

该命令只检查 `adb`/`xcrun` 和设备连接状态，**不会生成 FPS、P95、内存或通过结论**。沙盒中没有 Android/iOS 真机通道时，可用 `--allow-missing` 做准备性检查；完成实测后，再将 baseline/snow JSON 交给 `scripts/analyze_real_device_performance.py`，由其校验设备字段、帧时间和掉帧阈值。

## 仍须完成，才可称“真正上线”

1. **扩大轻量策略深度。**首条供应目标有完成判定与单次奖励，但其他热点只是信息展示，玩家仍可不移动就点访；要有完整可留存的游戏，还需第二条目标、区域差异化抉择及至少一个可反复执行的策略选择，而非继续罗列纯展示按钮。
2. **统一产品表面。**主界面其他旧模块和历史 README 仍有 ISC 代币、GameFi/科幻或 3D 文案及旧路由；开发入口已纠正，但全站必须做一次无 NFT/链上/误导文案审查，决定旧功能隐藏或清理。
3. **存档与账号范围。**当前适合单机浏览器试玩。若上线承诺玩家跨设备、换机或账号同步，则须新增经过鉴权的服务器存档与数据迁移；不能拿本地存储冒充。
4. **真机质量门禁。**至少在实际 iPhone 与 Android 横屏检查加载、图片清晰度、触点命中、HUD 遮挡、低内存恢复、日夜可读性、发热/电量和 Safari/Chrome 音频/触摸行为；目前没有真实设备结果。
5. **生产发布。**验证生产构建、存储图片路径、OAuth/服务端部署、公开域名和刷新后可访问 `/game`；部署后再次走完“进入→换区→走访→运营→补给→刷新恢复”的烟测。当前**未取得上线域名或成功发布通知**。

## 为什么不直接移植 RTS 引擎

《帝国时代 III》并未见官方发布可直接复用的游戏源码；0 A.D. 的代码 GPL v2、OpenRA 和 openage 是 GPL v3 系列。openage 官方还说明其当前玩法基本不可用并依赖原作素材。直接把 C++/C#/3D RTS 引擎搬进 React 手机网页，会增加移植和授权负担，不能替代本项目已实现的经营循环。实际选择是：**借鉴建筑成本→生产→销售→补给的机制，不复制 RTS 源码**；以 [Pocket City 开发者公开的 HTML/JS 移动优化实践](https://blog.pocketcitygame.com/optimizations-for-html-and-js-game-development/)作为工程参照。详细来源见[项目案例与引擎比较](./ice-snow-city-2d-production-case-study.md)。
