# Phase 67: 3D 建模指南 (3D Modeling Guide)

## 项目概述

**项目名称**: Ice Snow City (冰雪城)  
**设计周期**: 第 7-10 周  
**目标**: 完成所有角色、建筑和环境的 3D 建模

## 3D 建模规范

### 1. 角色建模规范

#### 玩家角色

**多边形预算**: 15,000 - 25,000 多边形

**建模流程**:
1. 基础人体建模 (使用参考模型)
2. 头部细节建模 (五官、耳朵)
3. 手部建模 (5 根手指)
4. 脚部建模
5. 衣服建模 (分离的网格)
6. 配饰建模 (手机、背包等)
7. 网格优化和清理
8. 绑定准备 (UV 展开)

**绑定规范**: 60-80 个骨骼

**UV 展开**:
- 身体: 2048×2048 纹理空间
- 衣服: 1024×1024 纹理空间
- 无重叠、无拉伸
- 边界留白 (2-4 像素)

**导出格式**: FBX 2020 或 glTF 2.0

---

#### NPC 角色

**多边形预算**: 10,000 - 20,000 多边形

**建模流程**:
1. 基础人体建模 (可基于玩家角色修改)
2. 头部细节建模 (根据职业特征)
3. 手部和脚部建模
4. 职业特定的衣服建模
5. 职业配饰建模
6. 网格优化
7. 绑定准备

**绑定规范**: 50-70 个骨骼

**UV 展开**:
- 身体: 1024×1024 或 2048×2048 纹理空间
- 衣服: 512×512 或 1024×1024 纹理空间
- 无重叠、无拉伸

**导出格式**: FBX 2020 或 glTF 2.0

---

### 2. 建筑建模规范

**多边形预算**: 5,000 - 15,000 多边形 (主体)

**建模流程**:
1. 基础结构建模 (墙、屋顶、地板)
2. 门窗建模 (可动部件)
3. 细节装饰建模 (栏杆、装饰品)
4. 内部细节 (可选)
5. 碰撞体积定义
6. LOD 版本创建 (远距离、中距离、近距离)
7. 网格优化
8. UV 展开

**LOD 版本**:
- LOD 0 (近距离): 100% 多边形
- LOD 1 (中距离): 50% 多边形
- LOD 2 (远距离): 25% 多边形

**UV 展开**:
- 主体: 2048×2048 或 4096×4096 纹理空间
- 细节: 1024×1024 纹理空间
- 无重叠、无拉伸

**导出格式**: FBX 2020 或 glTF 2.0

---

### 3. 环境资源建模规范

#### 树木和植被

**多边形预算**:
- 树木: 2,000 - 5,000 多边形
- 灌木: 500 - 2,000 多边形
- 花卉: 100 - 500 多边形

**建模方法**:
- 使用 SpeedTree 或手工建模
- 支持风吹动画 (可选)
- 创建 LOD 版本

**纹理**:
- 树木: 1024×1024
- 灌木: 512×512
- 花卉: 256×256

---

#### 道具 (Props)

**类型**: 路灯、长椅、垃圾桶、标志牌、栅栏等

**多边形预算**: 500 - 2,000 多边形

**建模流程**:
1. 基础形状建模
2. 细节建模
3. 网格优化
4. UV 展开
5. LOD 创建

**纹理**: 512×512 或 1024×1024

---

## 建模最佳实践

### 拓扑和流线

**头部拓扑**:
- 环形流线围绕眼睛
- 嘴部周围密集拓扑
- 鼻子周围流线清晰
- 耳朵与头部连接自然

**身体拓扑**:
- 肩膀处流线清晰
- 肘部和膝盖处环形流线
- 腋下和腹股沟处细致拓扑

**手部拓扑**:
- 每根手指环形流线
- 手掌中心流线清晰
- 手腕与前臂连接自然

### 网格清理

- [ ] 移除所有双面多边形
- [ ] 移除所有孤立顶点
- [ ] 合并重复顶点
- [ ] 检查法线方向一致
- [ ] 移除所有隐藏的内部几何

### 命名规范

**对象命名**:
```
[类型]_[名称]_[版本]
例如:
- Character_Player_v01
- Character_Farmer_Male_v01
- Building_House_v01
- Building_House_Upgraded_v01
- Prop_Streetlight_v01
```

**材质命名**:
```
[对象]_[部分]_[材质类型]
例如:
- Player_Body_Skin
- Player_Clothes_Fabric
- House_Wall_Brick
- House_Roof_Metal
```

**骨骼命名**:
```
[部分]_[位置]_[编号]
例如:
- Armature_Spine_01
- Armature_Spine_02
- Armature_Arm_L_01
- Armature_Arm_R_01
```

## 技术要求

### 软件工具

**推荐软件**:
- Blender (免费、开源)
- Maya (专业级)
- 3ds Max (专业级)
- ZBrush (高模雕刻)

### 导出设置

**FBX 导出**:
- 版本: FBX 2020
- 包含: 网格、骨骼、法线、UV
- 平滑组: 启用
- 单位: 厘米
- 轴向: Y 向上

**glTF 导出**:
- 版本: glTF 2.0
- 格式: .glb (二进制)
- 包含: 网格、骨骼、法线、UV、材质
