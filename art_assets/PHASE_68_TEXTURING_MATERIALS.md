## PBR 工作流程

### PBR 材质通道

每个材质需要以下纹理贴图：

| 贴图类型 | 用途 | 格式 | 说明 |
|---------|------|------|------|
| Albedo (颜色) | 基础颜色信息 | RGB | 无阴影、无光照信息 |
| Normal Map | 表面细节 | RGB (BC5) | 蓝色通道向上 |
| Roughness | 表面粗糙度 | 灰度 | 0 = 光滑, 1 = 粗糙 |
| Metallic | 金属性 | 灰度 | 0 = 非金属, 1 = 金属 |
| AO (环境光遮蔽) | 阴影信息 | 灰度 | 用于增强细节 |
| Height Map | 高度信息 | 灰度 | 用于视差贴图 (可选) |

### 材质类型

#### 皮肤材质

**Albedo 贴图**:
- 基础肤色 (无阴影)
- 均匀的色调
- 包含细微的肤色变化

**Normal Map**:
- 毛孔细节
- 皱纹和纹理
- 中等强度 (0.5-0.8)

**Roughness**:
- 皮肤: 0.4-0.6 (中等粗糙)
- 嘴唇: 0.3-0.4 (较光滑)
- 眼睛: 0.1-0.2 (光滑)

**Metallic**:
- 皮肤: 0.0 (非金属)

**AO**:
- 毛孔阴影
- 皱纹阴影
- 自然的阴影变化

---

#### 布料材质

**Albedo 贴图**:
- 布料颜色
- 织物纹理
- 自然的色彩变化

**Normal Map**:
- 织物纹理细节
- 强度根据布料类型调整
- 棉布: 0.4-0.6, 丝绸: 0.2-0.3, 牛仔: 0.7-0.9

**Roughness**:
- 棉布: 0.6-0.8
- 丝绸: 0.2-0.4
- 牛仔: 0.7-0.9
- 皮革: 0.5-0.7

**Metallic**:
- 布料: 0.0 (非金属)
- 金属纽扣: 0.8-1.0

**AO**:
- 褶皱阴影
- 接缝阴影
- 自然磨损痕迹

---

#### 金属材质

**Albedo 贴图**:
- 金属基础颜色
- 最小化阴影信息
- 均匀的颜色

**Normal Map**:
- 表面划痕和磨损
- 强度: 0.3-0.5 (细微细节)

**Roughness**:
- 抛光金属: 0.1-0.2
- 普通金属: 0.3-0.5
- 粗糙金属: 0.6-0.8

**Metallic**:
- 金属: 1.0

**AO**:
- 接缝和边缘阴影
- 磨损和划痕

---

#### 木材材质

**Albedo 贴图**:
- 木纹颜色

- 木纹纹理

**Normal Map**:
- 木纹细节
- 强度: 0.5-0.7

**Roughness**:
- 抛光木材: 0.2-0.4
- 普通木材: 0.5-0.7
- 粗糙木材: 0.8-0.9

**Metallic**:
- 木材: 0.0

**AO**:
- 木纹阴影

#### 砖石材质

**Albedo 贴图**:
- 砖石颜色

**Normal Map**:

**Roughness**:

**Metallic**:

**AO**:

|------|--------|------|

| 部分 | 分辨率 | 说明 |
|------|--------|------|
| 主体 (Albedo) | 2048×2048-4096×4096 | 高质量外观 |

| 细节 (Normal) | 1024×1024 | 装饰纹理 |
| 细节 (其他) | 1024×1024 | Roughness, Metallic, AO |

### 环境纹理

| 对象 | 分辨率 | 说明 |
|------|--------|------|

## 纹理优化

### 纹理压缩

**推荐格式**:
- Albedo: BC1 (RGB) 或 BC7 (RGBA)
- Normal: BC5 (RG)
- Roughness/Metallic/AO: BC4 (单通道)

**文件大小优化**:
- 使用纹理压缩减少文件大小
- 合并相关贴图 (如 Roughness + Metallic + AO)
- 移除未使用的 Alpha 通道

### 纹理打包

**打包策略**:
```
Roughness: R 通道
Metallic: G 通道
AO: B 通道
Reserved: A 通道
```

这样可以将 3 张 1024×1024 的灰度贴图合并为 1 张 RGBA 贴图。

## 材质库标准

### 材质命名规范

```
[对象]_[部分]_[材质类型]_[变体]
例如:
- Player_Body_Skin_Default
- Player_Clothes_Fabric_Shirt_01
- House_Wall_Brick_Weathered
- Tree_Bark_Wood_Oak
```

### 材质参数标准

**皮肤材质参数**:
- Roughness: 0.4-0.6
- Metallic: 0.0
- Subsurface Scattering: 0.5-0.8 (如果支持)

**布料材质参数**:
- Roughness: 0.4-0.9 (根据布料类型)
- Metallic: 0.0
- Anisotropy: 0.0-0.3 (如果支持)

**金属材质参数**:
- Roughness: 0.1-0.8 (根据金属类型)
- Metallic: 1.0
- Anisotropy: 0.0-0.5 (如果支持)
